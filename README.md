## 🏥 The Big Build — CareFlow CMS

<div align="center">

<img src="https://raw.githubusercontent.com/webneco/webneco/main/careflow.svg" width="100%" alt="CareFlow CMS — the visit loop" />

</div>

<br/>

**[CareFlow CMS](https://careflowcms.tech)** is a **multi-tenant clinic operating system** for solo doctors and multi-doctor clinics in India — mobile-first, installable as a PWA, and WhatsApp-native from the first booking to the follow-up nudge.

The whole product snaps together on one click. When a doctor taps **Confirm visit**, a single API transaction closes the loop:

- 🧾 sequential **invoice** created (`INV-{year}-{seq}`, PDF rendered on demand — never stored stale)
- ✅ appointment marked **COMPLETED**
- 🔁 **follow-up** scheduled from the next-checkup date
- ⭐ **review request** queued behind a rating gate (≥ 4★ → Google, below → private feedback)
- 💬 **WhatsApp** summary sent to the patient

Everything downstream is fire-and-forget, so a slow WhatsApp API never blocks the doctor's screen.

<div align="center">

| Brick | What clinics get |
|:------|:-----------------|
| 👤 **Patients** | Registration, `CF-` codes, history, allergies, tags, bulk import |
| 📅 **Appointments** | Booking, reschedule, check-in, slot conflict checks, digital consent |
| 🩺 **Consultations** | Vitals, diagnosis, treatment plan, prescriptions, billing line items |
| 🧾 **Billing & Invoices** | Per-clinic sequential numbering, on-demand PDF, payment status |
| 💬 **Engagement** | WhatsApp Cloud API, templates, delivery receipts, two-way inbox |
| ⭐ **Reviews** | Public rating gate that protects the clinic's public score |
| 🔁 **Follow-ups** | Recall rules + daily cron nudges, capped per patient |
| 📣 **Marketing** | Campaigns, audiences, referrals, consent + monthly send caps |
| 📊 **Dashboard & Reports** | Today's queue, revenue trends, funnels |
